# FUTURE_PE_01

# AI Website Copy Generator for Local Businesses

## Project Overview

This project was created as part of the **Future Interns – Prompt Engineering Task 1**.

The objective of this task is to use Prompt Engineering and AI tools to generate professional, conversion-focused website copy for a local business. The generated content includes a homepage, service descriptions, and persuasive call-to-action sections that are ready to be used on a real website.

---

## Business Details

- **Business Name:** Divine Cuisine
- **Website Name:** Divine Cuisine
- **Tagline:** Homely Food, Divine Bite
- **Business Type:** Cloud Kitchen
- **Location:** Mangalore, Karnataka

---

## Objective

To design a structured prompt that generates high-quality website copy for a local cloud kitchen using AI. The content is designed to improve customer engagement, build trust, and encourage online orders.

---

## AI Tools Used

- ChatGPT (GPT-5.5)
- Framer AI / Lovable AI (Optional for website design)
- GitHub
- Microsoft Word

---

## Project Deliverables

- Homepage Copy
- Services Page Content
- Call-to-Action (CTA) Sections
- Prompt Logic Documentation
- GitHub Repository

## Prompt Engineering Approach

A structured prompt was created by including:
- Business information
- Target audience
- Brand tone
- Website sections
- CTA requirements

This approach helped generate clear, engaging, and website-ready content specific to the business.

---

## Outcome

The AI successfully generated a complete website copy for **Divine Cuisine**, including a homepage, service descriptions, and strong call-to-action content. The generated content is suitable for a real business website and demonstrates the effectiveness of Prompt Engineering in creating professional marketing content.
